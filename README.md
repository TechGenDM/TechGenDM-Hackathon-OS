# Hackathon Operating System

This repository is a reusable operating system for running a hackathon project from idea through submission.

## Structure

- `01-Hackathon-Intelligence/` — rules, judging criteria, timeline, sponsor research
- `02-Idea-Research/` — competitor research, idea generation, scoring
- `03-Project-Planning/` — PRD, architecture, tech stack, roadmap
- `04-Development/` — tasks, implementation notes, decisions
- `05-Quality-Testing/` — test cases, bugs, deployment checks
- `06-Submission/` — README, pitch, demo script, final checklist
- `07-AI-Prompts/` — reusable AI instructions
- `Templates/` — reusable docs and checklists

## Suggested workflow

1. Define the hackathon constraints and judging rules.
2. Research competitors and score ideas.
3. Plan the product and technical architecture.
4. Build the MVP in focused tasks.
5. Validate quality and performance.
6. Prepare final pitch and submission materials.
7. Reuse prompts and templates for future hackathons.

## Maintenance

This repo can be copied and adapted for each hackathon event without starting from scratch.
